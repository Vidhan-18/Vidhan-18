## Featured Project

### 🛡️ [Honeypot Defense Platform](https://github.com/Vidhan-18/HoneyPot)

A production-ready multi-service honeypot that emulates SSH, HTTP, FTP, SMB, and database services to capture attacker behaviour in real time.

**What it does:**
- Logs unauthorized access attempts across 5 simulated services
- Detects IOCs automatically and fires Telegram/Slack/webhook alerts
- Visualizes attack origins on an interactive world threat map
- Classifies attack types: brute-force, credential stuffing, port scanning, reconnaissance

**Stack:** Python · Flask · Docker Compose · Wireshark · Socket.IO · Leaflet.js
